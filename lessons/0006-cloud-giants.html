0006 — 三大雲端巨頭：AWS, Azure, GCP 的定位差異

對應模組: Module 3 — 資料中心與雲端運算
預計時間: 15 分鐘

想像你要選擇一個「城市」定居：

AWS 就像是紐約：它是最早開發的，規模最大，什麼都有，無論你想要什麼樣的稀奇古怪的工具，這裡一定有。但因為太大了，導航（控制台）有時候會讓你感到迷路。

Azure 就像是華盛頓：它是政府與大型企業的聚集地。如果你已經在用微軟的 Office、Windows 或 Active Directory，住在這裡會感到極其親切，所有東西都整合得非常好。

GCP 就像是矽谷：它充滿了最前衛的技術。雖然城市規模沒有紐約大，但在 AI、大數據分析和容器化 (Kubernetes) 方面，它是全世界最頂尖的。

三大巨頭的基因分析

雖然三家提供的基本服務 (VM, VPC, Storage) 幾乎一樣，但他們的強項不同：

供應商核心基因最強項適合對象
AWS電商 $\rightarrow$ 基礎設施服務最完整、市場佔有率最高、文件最豐富。追求穩定、需要最多功能選項的企業。
Azure作業系統 $\rightarrow$ 企業軟體與微軟生態 (AD, .NET, SQL Server) 深度整合。深耕微軟生態的企業用戶。
GCP搜尋 $\rightarrow$ 數據/AI資料分析 (BigQuery)、機器學習 (TensorFlow)、K8s。數據驅動、AI 優先、追求開發效率的團隊。
為什麼我們選擇 GCP 實作？
除了 \$300 抵用金外，GCP 的控制台設計較為現代且直觀，對於初學者來說，學習曲線比 AWS 更平緩。此外，學習 GCP 能讓您更接近現代雲端原生 (Cloud Native) 的設計理念。

如何選擇正確的雲端平台？

在現實世界中，很多公司會採取 「多雲策略 (Multi-Cloud)」，即同時使用兩家或三家供應商，以避免被單一供應商綁架 (Vendor Lock-in)。

  • 成本導向：比較不同區域的價格 $\rightarrow$ 選擇最便宜的。
  • 技術導向：需要最強的 AI $\rightarrow$ GCP；需要最強的企業整合 $\rightarrow$ Azure。
  • 生態導向：團隊成員都熟悉 AWS $\rightarrow$ AWS。
