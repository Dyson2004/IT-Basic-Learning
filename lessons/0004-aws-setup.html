0004 — 準備你的雲端實驗室：AWS 帳號設定

對應模組: Module 2 — 伺服器、虛擬化與雲端實作準備
預計時間: 15 分鐘 (含帳號檢查)

想像你要進入一間「超級工具租賃店」。這間店裡有世界上最強的 CPU、最大的 RAM 和最快的網路。你不需要買下這些工具，只需要用信用卡登記一個帳號，就可以在需要時租用一個 CPU 一小時，或者租用一個 1TB 的硬碟一天。

AWS (Amazon Web Services) 就是這間租賃店。而這堂課的目的，就是確保你的「會員卡」已開通，且你設定了「消費限額」，以免不小心花掉太多錢。

1. AWS 帳號檢查

請確認您目前的狀態（選擇其中一項）：

  • 情況 A: 我已有 AWS 帳號，且能正常登入。 $\rightarrow$ 直接跳到步驟 2。
  • 情況 B: 我很久沒登入了，不確定是否還能使用。 $\rightarrow$ 請嘗試登入 AWS Console。
  • 情況 C: 我沒有帳號，或者想建立一個全新的學習帳號。 $\rightarrow$ 請至 aws.amazon.com 註冊。
重要提醒: 註冊 AWS 帳號需要信用卡。雖然 AWS 提供 12 個月的「免費等級 (Free Tier)」，但如果超過限額或使用了非免費服務，AWS 會直接從信用卡扣款。

2. 設定預算警報 (Billing Alarm) —— 這是最重要的一步！

為了防止「意外扣款」，請務必在進入任何實作前設定預算警報：

  1. 登入 AWS Console $\rightarrow$ 搜尋 「Billing」 (帳單)。
  2. 進入 「Budgets」 (預算) $\rightarrow$ 點擊 「Create budget」。
  3. 選擇 「Cost budget」 (成本預算) $\rightarrow$ 設定預算金額為 \$1.00 (或您能接受的金額)。
  4. 設定電子郵件通知：當實際支出達到 80% 或 100% 時，立即發信通知您。
導師建議: 很多初學者因為忘了刪除建立的 VM (EC2 實例)，導致月底收到驚人的帳單。設定預算警報是每個雲端工程師的「生存本能」。

3. 熟悉控制台 (Management Console)

AWS 的控制台就像是一個巨大的工具箱。您可以嘗試搜尋以下服務，看看它們長什麼樣子（暫時不需要操作）：

  • EC2 (Elastic Compute Cloud): 我們之後會在這裡建立「虛擬機」。
  • VPC (Virtual Private Cloud): 我們之後會在這裡建立「虛擬網路」。
  • S3 (Simple Storage Service): 雲端上的「大檔案櫃」。
反向驗證時間
這堂課不需要複雜的理論，只需要確認您的實作準備度。請告訴我：
  1. 您目前的 AWS 帳號狀態（已有 / 剛註冊 / 需幫助）。
  2. 您是否已經設定好「預算警報」？（如果還沒，請現在就去設定，設定好後再回覆我）。
  3. 您能從 Console 搜尋到 「EC2」這個服務嗎？
把您的狀態傳給我，確認準備就緒後，我們正式跨入 Module 3：資料中心與雲端運算！
