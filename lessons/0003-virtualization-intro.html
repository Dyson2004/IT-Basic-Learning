0003 — 虛擬化：打破硬體的枷鎖

對應模組: Module 2 — 伺服器、虛擬化與雲端實作準備
預計時間: 20 分鐘

想像你買了一套超級巨大的豪華公寓 (實體伺服器)，有 10 個房間，但你只有一個人住，這太浪費了。

虛擬化 (Virtualization) 就像是你在公寓裡安裝了「活動隔板」。你把這套大公寓切分成 5 個獨立的小套房，每個小套房都有自己的門鎖、電表和水錶。雖然他們共用同一個建築物（硬體），但住在 A 套房的人完全不知道 B 套房的存在，彼此互不干擾。

虛擬化的核心：Hypervisor (虛擬化管理程序)

在電腦世界裡，這個負責「安裝隔板」並管理資源的管家叫做 Hypervisor。

Hypervisor
Hypervisor / Virtual Machine Monitor (VMM)
它是一個特殊的軟體層，安裝在實體硬體之上。它的工作是：欺騙 上層的作業系統，讓作業系統以為自己獨佔了整台電腦的 CPU 和 RAM。

關鍵術語：Host 與 Guest

為了區分誰在管誰，我們使用這兩個詞：

術語對應角色簡單理解
Host (宿主機)實體伺服器提供肉體 (CPU/RAM/Disk) 的那台真實機器。
Guest (客體機 / 虛擬機)VM (Virtual Machine)住在 Host 裡面的「虛擬小電腦」。
為什麼要這麼做？
如果你想測試一個危險的軟體，你不需要買一台新電腦。你只需要在 Host 裡開一個 Guest VM，如果 VM 崩潰了或中了病毒，你只要把這個 VM 刪除就好，完全不會影響到 Host (實體機) 的安全。

虛擬化的三大好處

  1. 資源最大化 (Efficiency)：一台 64 核 CPU 的伺服器，可以切成 10 台 6 核的 VM，讓 10 個不同的網站同時運行，不再浪費資源。
  2. 環境隔離 (Isolation)：VM A 崩潰了，不會影響到 VM B。這對安全性至關重要。
  3. 快速部署 (Agility)：建立一台實體伺服器需要買零件 → 組裝 → 裝系統 (可能需要 3 天)；建立一個 VM 只需要點擊「建立」 → 複製模板 (只需要 3 分鐘)。
