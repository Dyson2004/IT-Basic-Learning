0012 — 尋找邊界：跳躍間距與範圍計算

對應模組: Module 5 — IP 位址與子網路劃分
預計時間: 30 分鐘

想像你在劃分一條「長長的街道」。街道總長 256 公尺，你現在要把這條街平均切成 4 個區塊。

你不需要拿尺去量每一公尺，你只需要知道「每隔 64 公尺」就有一塊新區塊的開始：
- 第一區：0m $\rightarrow$ 63m
- 第二區：64m $\rightarrow$ 127m
- 第三區：128m $\rightarrow$ 191m
- 第四區：192m $\rightarrow$ 255m

在網路中，這個「64」就叫做 「跳躍間距 (Magic Number)」。

1. 如何計算跳躍間距 (Magic Number)？

跳躍間距就是一個子網路所佔用的總 IP 數量（包含不能用的那兩個）。

計算方法：
公式：$256 - \text{遮罩最後一段的數值}$

以 /26 為例 (遮罩 255.255.255.192)：
$256 - 192 = \mathbf{64}$
結論：這個網路每隔 64 個 IP 就會開始一個新子網路。

2. 填寫範圍表格

有了跳躍間距 (64)，我們就可以像填空一樣列出所有子網路的範圍：

子網路 網路位址 (Network) 第一個可用 IP 最後一個可用 IP 廣播位址 (Broadcast)
Subnet 1 .0 .1 .62 .63
Subnet 2 .64 .65 .126 .127
Subnet 3 .128 .129 .190 .191
Subnet 4 .192 .193 .254 .255
快速檢查法：
- 網路位址：永遠是該區塊的第一個數。
- 廣播位址：永遠是下一個子網路位址的 -1 (例如 64 - 1 = 63)。
- 可用 IP：夾在中間的範圍。

3. 實戰案例：找出特定的 IP 屬於哪個網路？

如果有人給你一個 IP 192.168.1.100/26，你要如何判斷它在哪個子網路？

  1. 找出跳躍間距 $\rightarrow$ 64。
  2. 列出起始點 $\rightarrow$ .0, .64, .128, .192。
  3. 比對 .100 $\rightarrow$ 它在 .64 之後，但在 .128 之前。
  4. 結論：它屬於 Subnet 2 (範圍 .64 $\rightarrow$ .127)。
