0009 — IP 的語言：二進位與十進位

對應模組: Module 5 — IP 位址與子網路劃分
預計時間: 30 分鐘 (請放慢速度)

想像你在跟一個「只能眨眼」的外星人溝通：

他不能說話，只能透過「眨眼 (1)」或「不眨眼 (0)」來傳遞訊息。如果你想告訴他數字「3」，你不能直接說「三」，你必須設計一套規則，例如：眨一次眼代表 2，眨一次眼代表 1，兩次眨眼加起來就是 3。

電腦就是這個外星人。它的 CPU 和記憶體本質上是數以億計的微小開關。因此，無論你的 IP 位址看起來像 192.168.1.1，在電腦眼中，它其實是一串長長的 0 和 1。

1. 什麼是二進位 (Binary)？

我們人類使用 十進位 (Decimal)，因為我們有 10 根手指。而電腦使用 二進位 (Binary)，因為電路只有兩種狀態：開 (On/1) 或 關 (Off/0)。

  • Bit (位元): 二進位的最小單位。一個 Bit 只能是 0 或 1。
  • Byte (字節): 8 個 Bit 組合成一個 Byte。

2. 核心技能：二進位 ↔ 十進位轉換

要理解 IP 位址，你必須先掌握這個「權值表」。一個 Byte (8 bits) 的權值如下：

Bit 位置12345678
權值 (2的次方)1286432168421
二進位狀態01001010
計算範例：上面的二進位 01001010 是多少？
方法：將狀態為 「1」 的權值全部加起來 →
(0 × 128) + (1 × 64) + (0 × 32) + (0 × 16) + (1 × 8) + (0 × 4) + (1 × 2) + (0 × 1) =
64 + 8 + 2 = 74

3. 為什麼 IP 位址要這樣設計？

一個 IPv4 位址是由 4 個部分組成（稱為 Octet，八位組），每個部分都是 8 個 bits。

例如 192.168.1.1：
- 192 → 11000000 (128 + 64)
- 168 → 10101000 (128 + 32 + 8)
- 1 → 00000001 (1)
- 1 → 00000001 (1)

導師提醒: 不要試圖死背 IP 轉換表！請練習上面的「權值相加法」。這是後續學習「子網路劃分 (Subnetting)」的唯一基礎，如果這裡不熟，後面會非常痛苦。
