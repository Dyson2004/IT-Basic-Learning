0001 — 電腦裡面有什麼？硬體與軟體的分野

對應模組: Module 1 — IT 基礎概念與硬體組件
預計時間: 15–20 分鐘

本課目標

  1. 能區分「硬體」(Hardware) 與「軟體」(Software) 的差別。
  2. 能說出電腦 / 伺服器 / 手機共通的五大硬體元件。
  3. 能解釋 RAM 與 Storage 的關鍵差異(為什麼重新開機後 RAM 的東西會不見)。
先別管那些英文術語。想像你走進一間辦公室——

辦公桌、椅子、櫃子、電話，這些看得見摸得著的實體,就是「硬體(Hardware)」。
而桌上的工作流程表、作業標準書、會議議程這些「指導怎麼做事」的無形規則,就是「軟體(Software)」。

電腦世界也是一樣：硬體 = 設備實體，軟體 = 指導實體工作的指令。

硬體的五大元件

無論你拆開的是桌上型電腦、伺服器機房裡的機器，還是你的手機，裡面都有這五個核心部件:

元件英文辦公室類比一句話角色
中央處理器CPU主管本人執行指令、運算、調度所有資源
記憶體RAM辦公桌面暫時放「正在處理」的資料
儲存硬碟Storage檔案櫃永久保存資料
網卡NIC電話/信箱與外界(網路)溝通的門牌
顯示卡GPU專員助手專門處理圖像/平行運算
關鍵洞察: 「伺服器」其實就是一台強化版的電腦 —— 同樣有 CPU、RAM、Storage、網卡，只是規格更強、穩定性更高、不分晝夜開機運作。你手機的「處理器」、「記憶體」概念也完全一樣，只是體積更小。

RAM vs Storage: 一個讓你秒懂的問題

這是初學者最容易混淆的一對。請看下表對比:

RAM (記憶體)Storage (儲存)
類比辦公桌面檔案櫃
速度超快(秒讀)較慢(幾百到幾千倍)
大小小(8~64 GB 常見)大(512 GB ~ 多 TB)
斷電消失(揮發性)保留(非揮發性)
放什麼正在用的文件所有文件的收藏
為什麼重新開機後 RAM 清空? 因為 RAM 是「快速存取用」的電容器件，依賴持續供電維持資料。一旦斷電，桌面被「清空」。所以你必須先把文件「存檔」(從 RAM 寫入 Storage), 斷電後下次開機才能從檔案櫃中找回它。

軟體的兩層結構

軟體不是只有一種。它分為兩層:

作業系統 (Operating System, OS)
Operating System
「管理硬體的人」。所有應用程式想用 CPU、RAM、網卡，都必須透過作業系統。它是硬體與應用程式之間的「翻譯官」。
例如: Windows、Linux、macOS、Android、iOS。
應用程式 (Application, App)
Application
「執行特定任務」的軟體，必須運行在某個作業系統之上。
例如: Chrome(瀏覽器)、Excel(試算表)、Uber(叫車)、Line(通訊)。
反向驗證時間
請用自己的話回答以下三個問題（不要只回 OK 或懂了）:
  1. 如果把電腦比喻為辦公室，CPU、RAM、Storage 分別對應的角色是什麼？為什麼 RAM 像「桌面」而不是「檔案櫃」？
  2. 有人跟你抱怨「我電腦 1TB 又很多，為什麼開 Chrome 還會卡？你會怎麼解釋給他聽？
  3. Android 是「作業系統」還是「應用程式」？它跟 Line(應用) 的關係是什麼？
