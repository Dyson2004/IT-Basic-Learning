0002 — 伺服器：一台不休息的超級電腦

對應模組: Module 1 $\rightarrow$ Module 2 銜接
預計時間: 15 分鐘

想像你的個人電腦是一間「私人小廚房」：你隨時可以用它做早餐，不用時就關掉，壞了也沒關係，最多今天不吃飯。

而伺服器則像是一間「24小時營業的連鎖餐廳中央廚房」：它必須 365 天 24 小時不停運作，不能突然斷電，不能因為一個廚師請假就停擺，而且要能同時處理成千上萬份訂單。

伺服器 vs. 個人電腦 (PC)

雖然內部零件一樣，但伺服器的設計邏輯完全不同：

特徵個人電腦 (PC)伺服器 (Server)為什麼？
運作時間需要時開機，不用時關機24/7/365 永不關機使用者隨時都要能存取資料 (如 Google/FB)
硬體規格適中，追求平衡極高 (超多 RAM, 多顆 CPU)需要同時服務數千名使用者
可靠性壞了就修 / 重啟備援設計 (Redundancy)不能有「單點故障」(Single Point of Failure)
互動方式接螢幕、鍵盤、滑鼠遠端連線 (Remote Access)放在冷氣房機架裡，不需要螢幕
關鍵洞察: 你之前學過的 AWS 雲端服務，本質上就是 AWS 在巨大的資料中心裡，幫你「租用」這些強化版的伺服器。你不需要自己買硬體、拉電線、裝冷氣，直接透過網頁就能控制。

伺服器的「備援」概念 (Redundancy)

伺服器最怕的是「壞掉」。為了防止停機，伺服器通常會配置多份備份：

  • 雙電源：插兩個電源插座，一個跳電另一個還能撐著。
  • RAID (硬碟陣列)：資料同時寫入多顆硬碟，一顆壞了，資料還在另一顆。
  • ECC 記憶體：能自動偵測並修正 RAM 中的微小錯誤，防止系統崩潰 (Blue Screen)。

為什麼這很重要？ $\rightarrow$ 邁向虛擬化

伺服器雖然強大，但有個巨大的問題：資源浪費。

想像你買了一台超強伺服器 (CPU 64 核, RAM 512GB)，但你只需要跑一個簡單的小網站，這個網站可能只用了 1% 的資源。剩下的 99% 就這樣閒置在機房裡耗電。這就是為什麼後來人類發明了 「虛擬化 (Virtualization)」 —— 讓我們能把一台強大的實體伺服器，切成很多台「虛擬的小電腦」。
