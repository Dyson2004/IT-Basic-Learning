0014 — GCP 實作：親手建立您的第一個 VPC

對應模組: Module 6 — 路由與 VPC (實作篇)
預計時間: 40 分鐘

現在我們不再討論「披薩怎麼切」，而是直接打開 GCP 控制台，在雲端切出一塊真正的領地。這就像是在虛擬世界中蓋一座圍牆，並在牆上開幾個有守衛的門。

🛠️ 實作目標

建立一個名為 it-study-vpc 的網路，包含：

  • Public-Subnet: 10.0.1.0/24 (給網站伺服器用)
  • Private-Subnet: 10.0.2.0/24 (給資料庫用)

🚀 操作步驟

1 進入 VPC 頁面
登入 GCP Console $\rightarrow$ 搜尋欄輸入 VPC network $\rightarrow$ 點擊 「VPC 網路」。
2 建立 VPC
點擊 「建立 VPC 網路」 $\rightarrow$ 名稱填入 it-study-vpc $\rightarrow$ 子網路模式 選擇 「自定義」。
3 設定子網路 (重點！)
新增兩個子網路：
  • 名稱: public-subnet | 區域: 選擇您最近的區域 | IP 範圍: 10.0.1.0/24
  • 名稱: private-subnet | 區域: 選擇同一區域 | IP 範圍: 10.0.2.0/24
點擊 「建立」。
4 設定防火牆 (開門)
目前 VPC 是封閉的，我們需要開門讓流量進入。前往 VPC network $\rightarrow$ 「防火牆」 $\rightarrow$ 「建立防火牆規則」：
  • 名稱: allow-http-ssh
  • 目標: 選擇 「網路中的所有執行個體」
  • 來源 IPv4 範圍: 0.0.0.0/0 (代表允許全世界)
  • 通訊協定與連接埠: 勾選 TCP $\rightarrow$ 輸入 80, 22 (HTTP 與 SSH)
⚠️ 導師安全提醒: 在現實工作中，我們絕不會將 0.0.0.0/0 開放給所有連接埠。這裡為了學習方便而這樣設定，但請記得：權限越小越安全。

✅ 驗證清單

完成後，請檢查您的控制台是否看到：

  • [ ] 一個名為 it-study-vpc 的網路。
  • [ ] 兩個正確範圍的子網路 (10.0.1.0/24 與 10.0.2.0/24)。
  • [ ] 一條允許 TCP 80 和 22 的防火牆規則。
實作回報

「VPC 已建立完畢，確認無誤！」
如果您在操作過程中遇到任何錯誤訊息（例如：IP 範圍衝突或權限不足），請立刻截圖或把錯誤貼給我，我幫您排錯。
