0010 — IP 位址與子網路遮罩：界線在哪裡？

對應模組: Module 5 — IP 位址與子網路劃分
預計時間: 30-40 分鐘 (這是核心難點，請慢慢讀)

想像 IP 位址就像一個「完整的郵寄地址」，例如：台北市大安區信義路五段 1 號。

在這個地址中，包含兩個層級：
1. 區域 (網路 ID)：台北市大安區信義路五段 $\rightarrow$ 這決定了快遞員要把信送到哪個區域。
2. 門牌 (主機 ID)：1 號 $\rightarrow$ 進入該區域後，決定具體交給哪一戶。

問題是：電腦讀取 IP 時，它只看到一串數字（例如 192.168.1.10），它怎麼知道哪裡是「區域」，哪裡是「門牌」？
這時候，它需要一張 「遮罩 (Subnet Mask)」 把它蓋上去。

1. 子網路遮罩 (Subnet Mask) 的原理

子網路遮罩的規則非常簡單：連續的 1 代表「這是網路部分」，連續的 0 代表「這是主機部分」。

看到沒？前三個部分全部是 1 (255)，最後一個部分全部是 0。這告訴電腦：「前三個數字是社區名稱，最後一個數字才是門牌號碼。」

2. 核心運算：AND 運算 (邏輯與)

電腦如何利用遮罩算出網路位址？它使用一種叫 AND 的邏輯運算。規則只有一個：只有兩個都是 1，結果才是 1；否則都是 0。

範例：計算 IP 192.168.1.10 的網路位址 (遮罩 255.255.255.0)
(我們簡化只看最後一個八位組)
IP 最後一段: 00001010 (10)
遮罩最後一段: 00000000 (0)
AND 運算
結果: 00000000 (0)
結論: 該 IP 的網路位址 (社區名稱) 是 192.168.1.0
關鍵洞察: 只要遮罩是 255，對應的 IP 位址會原封不動地保留；只要遮罩是 0，對應的 IP 位址會全部變成 0。

3. 網路位址 vs. 廣播位址

在每一個子網路中，有兩個特殊的 IP 是絕對不能分配給電腦使用的：

  • 網路位址 (Network Address)：主機部分全為 0。例如 192.168.1.0。它代表這個社區本身。
  • 廣播位址 (Broadcast Address)：主機部分全為 1。例如 192.168.1.255。它像是一個巨大的喇叭，發送到這個地址的訊息，社區內所有人都能收到。
