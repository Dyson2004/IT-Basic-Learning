0004 — 準備你的雲端實驗室：GCP 帳號設定

對應模組: Module 2 — 伺服器、虛擬化與雲端實作準備
預計時間: 15 分鐘 (含帳號檢查)

想像你要進入一間「超級工具租賃店」。這間店裡有世界上最強的 CPU、最大的 RAM 和最快的網路。你不需要買下這些工具，只需要用 Google 帳號登記，就可以在需要時租用一個 CPU 一小時，或者租用一個 1TB 的硬碟一天。

Google Cloud Platform (GCP) 就是這間租賃店。而這堂課的目的，就是確保你的「會員卡」已開通，並領取那筆珍貴的「創業啟動金」。

1. GCP 帳號與抵用金 (Credits) 檢查

請確認您目前的狀態（選擇其中一項）：

  • 情況 A: 我已有 GCP 帳號，且能正常登入。 $\rightarrow$ 直接跳到步驟 2。
  • 情況 B: 我很久沒登入了，不確定是否還能使用。 $\rightarrow$ 請嘗試登入 GCP Console。
  • 情況 C: 我沒有帳號，或想建立新帳號領取抵用金。 $\rightarrow$ 請至 cloud.google.com 註冊。
關於 \$300 抵用金: 新用戶註冊 GCP 通常會獲得 90 天的 \$300 抵用金。這筆錢會優先於您的信用卡扣款。只要在 90 天內且金額未超過 \$300，您的信用卡不會被扣款。

2. 設定預算警報 (Billing Budgets) —— 雖然有抵用金，但仍建議設定！

即使有抵用金，設定警報依然是好習慣，能讓您清楚掌握資源消耗速度：

  1. 登入 GCP Console $\rightarrow$ 搜尋 「Billing」 (結算)。
  2. 進入 「Budgets & alerts」 (預算與警報) $\rightarrow$ 點擊 「Create budget」。
  3. 設定預算金額（例如設定為 10 美元，因為您有 300 美元抵用金，這只是用來觀察趨勢）。
  4. 設定通知閾值：當支出達到 50%、90% 時發信通知。

3. 熟悉控制台 (Google Cloud Console)

GCP 的界面與 AWS 不同。請嘗試搜尋以下服務，確認您可以找到它們：

  • Compute Engine: 我們之後會在這裡建立「虛擬機 (VM)」。 (對應 AWS EC2)
  • VPC network: 我們之後會在這裡建立「虛擬網路」。 (對應 AWS VPC)
  • Cloud Storage: 雲端上的「大檔案櫃」。 (對應 AWS S3)
反向驗證時間
這堂課不需要複雜的理論，只需要確認您的實作準備度。請告訴我：
  1. 您目前的 GCP 帳號狀態（已有 / 剛註冊 / 需幫助）。
  2. 您是否已確認收到 \$300 抵用金？（在 Billing 頁面可以看到餘額）。
  3. 您能從 Console 搜尋到 「Compute Engine」這個服務嗎？
把您的狀態傳給我，確認準備就緒後，我們正式跨入 Module 3：資料中心與雲端運算！
