# 學習記錄 0001: 起點評估與學習路線確立

**日期**: 2026-07-08
**模組**: 課前準備
**標題**: initial-assessment-and-learning-path

## 背景

學習者希望透過 freeCodeCamp.org 的 IT Fundamentals Course (13 小時)系統化學習 IT 基礎。學習者已具備 AWS CLF-C02 課程基礎。

## 學習者現況評估

### 動機
- 純粹個人興趣與自我提升。
- 非職涯轉換，但希望對工作有幫助。

### 既有知識
- 已完成 AWS Certified Cloud Practitioner (CLF-C02) 繁體中文版課程。
- 對 IaaS/PaaS/SaaS、AWS 服務有初步認識。
- 對硬體、網路、OSI 模型等底層知識的熟悉程度待確認。

### 工具
- 主要教材: YouTube 影片
- 輔助工具: Google NotebookLM

## 學習路線決策

1. **從 Module 1 開始**: 儘管學習者有 CLF-C02 基礎，仍需從硬體基礎開始，確保知識鏈完整。
2. **Module 3 加速**: 雲端服務模型學習者已熟悉，可加速但仍需反向驗證。
3. **Module 5 放慢**: 子網路劃分是核心難點，需特別著重。
4. **Module 7 類比輔助**: OSI 模型抽象度高，需大量生活化類比。

## 關鍵洞察

- 學習者的 CLF-C02 知識屬於「雲端服務使用者視角」，欠缺「底層硬體與網路視角」。本課程正好補足這個缺口，形成完整的 IT 知識鏈:硬體 → 網路 → 雲端 → 自動化。
- 因為是個人興趣導向，教學節奏可較彈性，但反向驗證仍不可省，以確保真正理解。
