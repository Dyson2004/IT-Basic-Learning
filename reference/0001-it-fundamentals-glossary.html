IT 基礎完整詞彙表

本詞彙表是您學習過程中的中央知識庫。每當課程進入新模組，此表將同步更新。

Module 1: IT 基礎概念與硬體

硬體 Hardware

電腦系統中所有實體、可觸摸的組件。

中央處理器 CPU (Central Processing Unit)

電腦的「大腦」，負責執行指令、運算與調度所有硬體資源。

隨機存取記憶體 RAM (Random Access Memory)

電腦的「短期工作台」，臨時存放 CPU 正在處理的資料。斷電後資料消失。

儲存硬碟 Storage (HDD / SSD)

電腦的「檔案櫃」，長期保存資料。斷電後資料不消失。

網路卡 NIC (Network Interface Card)

電腦連上網路的「門牌信箱」，負責資料轉換為訊號傳輸。

顯示卡 GPU (Graphics Processing Unit)

專責圖形運算與平行運算的處理器。

作業系統 Operating System (OS)

管理硬體資源的軟體，是硬體與應用程式之間的翻譯官。

應用程式 Application (App)

執行特定任務的軟體，運行在作業系統之上。
Module 2: 伺服器與虛擬化

伺服器 Server

強化版的電腦，設計目標為 24/7 不間斷運作且服務多個使用者。

備援 Redundancy

配置多份備份（如雙電源、RAID）以確保單個零件損壞時服務不中斷。

單點故障 SPOF (Single Point of Failure)

系統中若某個單一元件失效，會導致整個系統崩潰的臨界點。

虛擬化 Virtualization

透過軟體將實體硬體切割成多個獨立虛擬環境的技術。

虛擬化管理程序 Hypervisor

負責管理實體資源並將其分配給各個虛擬機 (VM) 的管家軟體。

宿主機 Host

提供實體硬體資源的真實電腦。

客體機 / 虛擬機 Guest / VM (Virtual Machine)

運行在 Host 之上的獨立虛擬電腦，擁有自己的 OS。
Module 3: 資料中心與雲端運算

地端 On-premises

在自有機房中部署和管理實體硬體。

資本支出 CapEx (Capital Expenditure)

一次性投入大筆資金購買資產 (如買伺服器)。

營運支出 OpEx (Operational Expenditure)

按使用量支付的日常費用 (如租用雲端服務)。

基礎設施即服務 IaaS (Infrastructure as a Service)

提供虛擬硬體，使用者需自行管理 OS 與應用程式 (如 GCP Compute Engine)。

平台即服務 PaaS (Platform as a Service)

提供開發環境，使用者只需專注於撰寫程式碼。

軟體即服務 SaaS (Software as a Service)

直接提供完整成品軟體，使用者直接操作 (如 Gmail)。

多雲策略 Multi-Cloud

同時使用多家雲端供應商以避免被單一供應商綁架 (Vendor Lock-in)。
Module 4: 網路基礎知識

區域網路 LAN (Local Area Network)

覆蓋單一辦公室或家中的私有高速網路。

廣域網路 WAN (Wide Area Network)

連接不同城市或國家的長距離網路。

交換器 Switch

LAN 的核心設備，根據 MAC 地址精準將資料送至目標電腦。

路由器 Router

跨網路的導航員，負責將資料在不同網路之間路由 (Routing)。

網路拓樸 Topology

設備之間物理連接的形狀（如星狀、網狀）。

封包 Packet

網路傳輸的最小單位，包含寄件人、收件人地址與內容。
Module 5: IP 位址與子網路 (進行中)

二進位 Binary

僅由 0 和 1 組成的數制，是電腦底層溝通的語言。

位元 Bit

二進位的最小單位，代表一個開關狀態 (0 或 1)。

字節 Byte

8 個 Bit 組合成的一個單位。
